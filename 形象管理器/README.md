# 形象管理器

面向曹操传加强版 6.4、6.5/6.5pl 与 6.6 修正版的独立 WinForms 图片资源管理工具，运行时不依赖工具整合包。

最新版本 `1.2026.1027.1`，入口为 [形象管理器.exe](发布-真实图片写回修正版-20261027/形象管理器.exe)，统一副本在 [交付目录](../交付/宝物拓展与真实图片写回修正版-20261027)。与 data 管理器使用相同的图片修复：RAW8／索引 BMP 按目标色表选色，透明擦除优先于保留旧索引，未编辑的半透明 ARGB 无损复制；跨色表换色要求所有目标区段都能表达目标色，可勾选“换色仅当前区段”。写回后复读实际目标，无变化不生成成功历史。操作见 [一体化管理器使用说明](docs/一体化管理器使用说明.md)，实测范围与限制见 [验收报告](../data管理器/验证/宝物拓展与真实图片写回-20261027/验收报告.md)。

本版新增/替换图片可在转换预览中选择 BMP（默认）、PNG 或保留原格式；专用结构按能力锁定。导入窗口将目录工具收在映射页，预览支持简洁结果列表、三栏对照和可展开详情。6.6 RAW策略动画按项目调色板解码与写回，修复山贼首个大动画发黑，并保留原有透明渐变。验收见 [本轮报告](../验证/图片导入与调色板修正-20261023/验收报告.md)。

## 启动

- 开发构建：`dotnet build ImageManager.sln`
- 测试：`dotnet run --project src/ImageManager.Tests`
- 单文件发布：`dotnet publish src/ImageManager.App/ImageManager.App.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o 发布-图片导入与调色板修正版-20261023`
- 直接启动：`发布-图片导入与调色板修正版-20261023\形象管理器.exe`（需要 .NET 8 Desktop Runtime x64）
- 打开程序后选择包含 `Ekd5.exe` 的游戏项目目录。

所有写入都先在 `形象管理器_备份\<项目名>_<路径哈希>\History` 创建完整文件快照。未可靠识别的项目只读打开。

详细操作与批量命名规范见 [docs/使用说明.md](docs/使用说明.md)，格式证据和验收结果见 [docs/样本验收报告.md](docs/样本验收报告.md)。

6.4 以洗隋为基底，使用 EXE 的数字版本资源识别引擎；DLL 图标不会把它误判为 6.5。人物 R/S 指定需通过当前 EXE 的完整消费者及 PE 映射验证，编辑后继续按消费者识别，同布局作品可复用。洗隋带重定向目录的 Face.e5 已增加受限格式识别；证据、保护条件与测试命令见 [6.4 图像适配验收](docs/6.4图像适配验收.md)。

S 形象图库按物理 Unit 图号管理：“兵种”为 `S_001～S_240`，“将领”为 `S_241` 起至档案末尾；每项包含同一物理号的 mov／atk／spc 共 28 帧，缩略图固定为移动第 0 帧。人物数据里的“S形象编号”另用工具整合包一致的紧凑编号：0 为当前兵种我军，1～32 各对应连续三张将领图，33 起各对应一张图。两种编号不能直接互填；一体化管理器的人物 S 编号下拉只显示数字，下方图片预览显示对应第一转的移动第 0 帧。

兵种 ID 为 `j` 时，我／友／敌军物理号依次为 `3j+1`、`3j+2`、`3j+3`；一体化管理器的兵种详情从上到下同时显示这三张移动第 0 帧。将领删除仅删除所选物理号并前移其后条目，Data 人物引用不自动调整；兵种删除只清空固定槽。将领复制追加只复制所选物理号的完整 28 帧。

S 原生动作条导出到 `将领/S_242/` 或 `兵种/S_002/`，参考总图为对应类型目录中的 `S_242.png`／`S_002.png`，单帧 PNG 放在各自物理号子目录。导回先明确选择物理编号或旧编号格式，再核对目标：旧将领 `S002` 对应物理 242，旧兵种 `兵种S001` 对应物理 2；批量导入不会自动猜测或平移编号。完整说明见 [一体化管理器使用说明](docs/一体化管理器使用说明.md)。
