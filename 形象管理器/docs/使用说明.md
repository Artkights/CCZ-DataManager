# 形象管理器使用说明

## 页面

- 人物形象：`Data / R 形象 / S 形象`。Data 左侧固定显示角色名、R 编号、S 编号；角色名与内部职业号只读。6.5/6.5pl 与已识别的 6.6 都可用 `Ctrl+S` 保存指定，写入位置为 R=`Ekd5.exe@0xE1000`、S=`Ekd5.exe@0xD2800`，且只修改变化字段。
- 人物头像：按 Data 头像号展示；0 是 Face 的八表情组。缺少 `Tou.dll` 时显示小头像降级模式。
- 宝物图标：6.5 读取 DLL RT_BITMAP，6.6 使用 `Item.e5` 的小图 `2N+1`、大图 `2N+2`；界面只显示、导出和编辑大图，小图由大图自动生成。
- 策略图标：DLL 以最小 RT_BITMAP ID 为基准，将 `base+2N` / `base+2N+1` 显示为同一字段的小图/大图；已验证的 `Mtem.e5` 同样按 `2N+1` / `2N+2` 配对显示。资源容器按实际格式独立检测，不只依赖引擎版本。
- 场景图片：Logo、Mmap、Tr、Gate、Pmap 等资源。
- 其他图片：范围、界面、动态图片、半身像、策略动画及自动发现的有效 E5。
- 历史记录：显示前后 SHA-256、完整快照、状态，并提供撤回、前进和永久保留。

Data 右侧 R 预览为正面、背面各前四帧；S 预览为攻击条的正面 0..3、侧面 8..11、背面 4..7。Data 顶部可切换转数，不支持多转的职业或 S 编号会自动回到一转，不写回 Data。

R/S、头像、图标及其他资源页不分页，完整筛选结果位于一个连续滚动区；只异步解码可见行和上下缓冲行。S 页区分将领与兵种，并按 Unit 文件物理顺序逐张展示。物理 1～240 为兵种固定槽；物理 241 起分别对应将领 `S001..SMax`，每项为同一图号的 mov/atk/spc，共 28 帧。每卡只显示对应站位的第一张代表帧。`S000` 依赖当前兵种 ID，只在 Data 页预览。`空闲` 默认关闭并按 Data 的逻辑 S 编号过滤。`背景色` 只出现在 R、S 和宝物页，默认开启且只影响预览。

## 图片文件新增与替换

普通静态图片支持 BMP、PNG、JPG、JPEG、GIF、TIF、TIFF、ICO、WebP，按实际文件内容解码；GIF、TIFF、ICO、WebP 使用首帧、首页面或首目录项作为静态素材并在详情注明，这不是大小动画导入。文件名、色深和来源尺寸可以任意。新增、替换先在“图片导入”窗口逐项映射，点击“准备转换并预览”，检查当前目标、源图裁切范围与实际候选，再确认一次写入。重复文件候选不会自动选定；换源、修改映射或外部改变素材后须重新准备。

R/S 素材限 BMP、PNG、JPG、JPEG，保持下列标准动作条尺寸与帧数。其余静态素材自动适配目标 MOD 的实际画布、调色板与存储编码。普通 E5 最近邻填满目标画布，新增使用末尾条目模板，BMP 保留位深、调色板及行序，PNG/JPG 保持目标编码，已确认 RAW 保留已知画布与合法尾部。DLL 替换分别保留所选 ID 各语言变体的画布、DIB 色深和调色板；新增以最小数字 ID 的变体为模板，使用最大 ID 加 1。空容器、未知尾部或模板无法可靠确认时停止导入。预览显示最终编码、量化和裁切后的实际候选。

头像按目标规格居中裁切，标准 Face 为 120×120 PNG32；旧 RAW 头像按已确认的原画布和项目调色板处理。Face 与 Tou 各自从同一原始素材生成，Tou 保留原变体画布与色深。Face0 的替换映射列出表情0～7，每个表情可手动分配任意尺寸素材，选图自动勾选，只写入指定表情和对应 Tou 项。宝物、策略图标的大小图可分别指定；未选小图时从完整大图最近邻派生。原像素编辑的编码、未修改索引、合法尾部及既有小图卷积路径保持。

地图“替换图片”只更新底图，任意尺寸素材自动转为当前地图的 JPG 画布；“导入地图与地形”另提供目录成对导入。`Mxxx.BMP` 固定为专用地形网格，必须保持原格数与结构；底图使用同名其他图片格式，BMP 底图使用另名如 `Mxxx_image.bmp`。多个底图候选会拒绝自动选择；地图固定槽不开放新增。天气的已验证43200字节条目支持新增和替换，自动转换为216×200四帧竖条并按项目调色板量化，新增只追加，禁止删除/重命名编号。Pmap已验证模板支持新增和替换，自动匹配目标画布和调色板并保留16字节专用头，禁止删除/重命名编号；Pmap像素编辑暂不可用。

Meff、Mcall 大小动画继续选择完整动画包，保留原有播放记录、帧平面与结构校验；普通静态首帧素材不代替动画包。

## R/S 批量素材

- “导出图片／替换图片”使用下列原生动作条；与“导出／导入参考图”的 AI 总图流程分开。S 每项始终对应同一物理图号，不把相邻图号展开为多转写入。
- R 新增目录：`R<ID>\front.bmp` 与 `R<ID>\back.bmp`。两图均为 `48x1280`，各含 20 帧。
- S 物理目录例如 `将领/S_242/`、`兵种/S_002/`，内含 `mov.bmp`、`atk.bmp`、`spc.bmp`。尺寸分别为 `48x528`、`64x768`、`48x240`；将领一次新增形成一个物理号的完整 28 帧，兵种只原位替换固定槽。
- 兵种S卡片标题为“兵种ID：兵种名称 我/友/敌军”，名称从详细兵种0开始对应；例如山贼物理图1～3分别显示“0：群英 我军/友军/敌军”。物理图号仍用于资源操作、搜索和导出目录。
- 素材限 BMP、PNG、JPG、JPEG，允许任意文件名，通过映射指定动作；动作条尺寸和帧序必须相同。替换允许缺省动作保持原图，新增须完整组。
- R 文件导入输出 PNG32；S 替换按已有目标分别输出 RAW8、BMP32 或 PNG32，新增 R/S 输出 PNG32。图片格式放宽不改变动作尺寸、帧数和物理映射。
- S 素材目录须明确选择物理编号或旧编号；旧 `S002` 对应物理 242，旧 `兵种S001` 对应物理 2，不自动猜测或展开 `turn2/turn3`。

新增始终追加到末尾。删除后后续编号前移，但不更新 Data、物品、策略、脚本或地图引用。兵种 S 的前 240 个物理槽为固定槽，删除只清空；Face 0 八图组为固定结构槽，禁止物理删除。S 新增要求三个 Unit 文件的图片数量一致，以保证新增动作仍使用同一物理图号。

## R/S 参考总图

- 默认导出当前逻辑编号、当前预览套的一张键色 PNG 和一份提示词。可选择额外导出格位完全相同的 `.transparent.png` 观察版，以及 2 倍、4 倍最近邻放大。提示词依据实际输出画布生成，包含格位坐标、帧序、动作、方向、空白格、键色、像素网格和人物基线约束。
- 新流程不生成、不查找、也不依赖 `.manifest.json`；目录里遗留的旧 JSON 会被忽略。单选导入允许任意 PNG 文件名，批量导入必须按已勾选逻辑编号命名为 `R<ID>.png` 或 `S<ID>.png`。
- 只接受正方形无损 PNG，不接受 JPG。当前选中的逻辑 R/S 及程序内固定布局是帧语义、物理条目映射和写入目标的唯一依据。
- R 顺序：front 0..19、back 0..19。
- R 标准画布为 448x448、40 帧。S 使用语义与尺寸分区：48x48 的 mov/spc 集中排列，64x64 的 atk 集中排列；帧间距固定 2px、分区间距固定 4px。当前套标准画布为 348x348、28 帧。旧三转 592x592、84 帧总图仅在导入时显式启用兼容选项，不作为默认导出。
- S 每转的 mov0..5、mov6..10、spc0..4 分别占一行；atk0..3、4..7、8..11 分别为正面、背面、侧面三行。空白保留格必须保持为空。

### AI 图片导回

- 优先要求 AI 严格保持本次导出画布尺寸和格位。标准尺寸直接按固定矩形切帧，整数倍输入使用最近邻一次还原；1024、1254、1536 等非标准尺寸只作为自动配准修复的兼容输入，不能保证任意重排均可恢复。
- 默认使用“自动修复＋像素清晰”和最近邻，不使用面积卷积、Lanczos3 或抖动；这些仅保留为用户主动选择的高级选项。非标准图先配准 mov/spc 的 48px 区、atk 的 64px 区及各语义行，再逐帧映射到原生尺寸。
- 有 Alpha 或键色时直接恢复透明背景。不透明黑底/纯色底会从边框估计背景并做边界连通洪泛、轮廓恢复；黑色背景与黑色服装无法数学上完全区分，所以黑底恢复始终标为有损并要求人工确认。
- 导入必定打开确认窗口，显示原图尺寸与倍率、背景蒙版、标准总图、逐帧动画和四阶段帧对比：原始项目参考帧、AI 原始帧、几何对齐帧、最终 CCZ 调色板帧。逐帧诊断同时列出源/目标矩形、原始/AI/对齐后的前景框、缩放比例、基线偏移、AI 与原图的内容误差、调色板颜色误差、键色命中和裁切状态。可用背景取色、保留/移除画笔、撤回/重做、全局/分区/单帧位移和缩放修正。
- 28/40/84 个必需帧不完整、保留空格被占用或发生无法解释的错格时，确认写回按钮不可用。仅有低置信度警告时，必须勾选“已检查低置信度、蒙版和裁切区域”。
- 默认不按旧人物前景框再次缩放新形象。原图用于格位、朝向和基线检查，不强制把 AI 新服装、新武器拉回旧人物轮廓；需要时可主动开启几何对齐。AI 本身的重绘差异保留为人工诊断。
- 位移使用整数像素拷贝，默认还原路径只做一次最近邻映射，避免二次平滑。前景、黑底恢复和裁切不可靠时必须在确认窗口中修正；后台重跑会取消旧任务，迟到结果不回填。
- 索引目标写回前将透明像素映射到键色，其他像素按目标调色板量化，并保留精确索引；原始 BMP/PNG/RAW 编码分别保持。BMP 自身色表优先，重复色索引及合法尾部在无修改时保持。真彩目标不强制转成 RAW8。最终 R 正/背或 S mov/atk/spc 条的尺寸和帧序保持不变。
- 黑底及近黑噪声的背景恢复属于有损处理：只做边界连通的背景移除，不全局替换黑色；黑色服装、帽檐和轮廓可能需要保留画笔人工修正。黑底、低置信度和几何裁切是警告，结构性缺帧、错格或保留空格被占用才会阻止写回。
- 优先将不带 `.transparent` 后缀的键色 PNG 交给 AI，并要求 AI 保留格子数量、动作顺序、空白格与整体拓扑。若 AI 强制把背景改黑，导回时必须逐帧检查轮廓。

## 批量改名

批量改名递归扫描子目录，保留扩展名。可使用查找替换、前后缀或模板。模板变量：

`{type}`、`{id}`、`{turn}`、`{action}`、`{side}`、`{index}`

执行前会检查重复名、非法字符、现存目标和大小写冲突，再用临时名做两阶段改名。映射保存在项目历史目录的 `rename-maps`。

## 写入安全

每次写入依次执行候选生成与复读、完整快照、目标替换、写后 SHA-256 与结构复读、历史落盘。多文件事务任何目标失败都会从写前快照恢复已写目标。撤回要求当前 SHA 等于对应写后 SHA，前进要求当前 SHA 等于撤回后的写前 SHA；不一致时拒绝覆盖并标为冲突。

`.eex` 是剧本，`.E5S` 是存档信息，永远不作为图片资源扫描。

## 当前安全边界

- 6.5/6.6 的 E5、R/S、Face/Tou、6.6 Item/Mtem 与 DLL RT_BITMAP 已可预览；R/S 可批量增删、参考图批量导入导出和像素写回。
- 通用 E5 可增删、替换、导出和像素写回；多条目资源按提交前映射操作。
- DLL RT_BITMAP 支持成对新增、替换、删除前移、导出和像素写回；候选 DLL 会先重新枚举资源再提交。
- Face/Tou 完整模式支持双文件新增、替换、删除和像素写回；Tou 缺失时只写 Face 并明确记录降级警告。
- 战场地图可单独转换替换底图，也支持底图与 `Mxxx.BMP`、Hexzmap 地形层成对导出/导入；底图自动适配目标画布，地形格数或块长度不匹配时拒绝写入。
- 策略页按 144 行策略表展示名称、图标、Meff 和 Mcall 字段；共享图标保留多行，动画按头部间隔播放。
- Meff 来自 `Ekd5.exe@668000`，Mcall 来自 `@668144`。动画按 20 字节记录中的帧引用播放；帧平面写回只覆盖明确修改的平面，记录区、其他平面、标志、音效参数、未知字段与尾部保持原字节。导出动画时会同时生成逐帧 PNG 和可用于整包替换的 `.animation.bin`。
- Pmap、Weather、DT 使用独立格式解码；已验证 Weather 每条为 216x200、43200 字节，按自上而下四个 216x50 帧循环，可自动转换静态素材新增/替换完整条带或编辑单帧，禁止删除/重命名编号。Pmap已验证模板支持静态素材新增/替换，保留专用头，暂不开放像素编辑。其他动画依据各自结构和引用播放，不统一使用四帧。游戏场景背景与特殊辅助遮罩尚未完整复现，相关原始字节保留。Mark 明确识别为非标准 E5，在完成逐字节往返验证前只显示专用格式诊断。
- R/S 像素编辑载入完整源条并纵向拼接；支持 25%–3200%、适合宽度、100%、Ctrl+滚轮锚点缩放、区段边界与帧边界。换色在独立窗口中最多五组并行执行；索引资源的目标色必须从项目 256 色调色板中选择。
- Mark 实验布局向导尚未开放写入；未知 Mcall 变体和 Mark 保持只读诊断，不显示可执行写入按钮。
- 结构探针通过的 Mcall 支持预览、逐帧 PNG/原始动画包导出、末尾新增独立文件、删除文件、整包替换和单平面像素写回。新增按项目现有补零风格使用下一个文件编号；删除会列出已知策略引用。两者都进入文件存在性事务，可撤回/前进，但不会自动修改策略表字段。
- Meff 支持经过结构验证的动画包条目新增、替换、删除、导出和帧平面写回；普通 PNG/JPG 不会被误写成动画包。
