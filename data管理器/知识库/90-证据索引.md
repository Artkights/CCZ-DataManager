## 本轮 6.6 消费者证据

6.6 的 R/S 和策略施展地形不再按 6.5 偏移猜测。PE32 节映射与唯一消费者签名在 `验证/本轮逆向/66-layout-scan.json`、`6.6-RS-策略地形-消费者证据.md` 和 `inspect_66_layouts.py` 中留有可复核记录：R 为 VA `0x50F800` → `Ekd5.exe +0xE1000` 的 1024×2 字节表；S 为 VA `0x501000` → `+0xD2800` 的 1024×2 字节表；策略地形消费者读取 VA `0x420ACC` → `+0x1FECC` 的 30×1 字节低四位掩码表。只有消费者签名、可写节、边界和样本值检查同时通过时才开放写回；无证据样本保持 `Unavailable`。

本轮迁移隔离回归覆盖根目录/E5 同名资源、字段级 SHA 隔离、配置快照失效和路径穿越拒绝。机器可索引的完整地址、尺寸、编码、Variant 和写回门禁以 `_github-kb-target/6.5`、`_github-kb-target/6.6` 下的 JSON 为准；其生成结果必须通过 `tools/validate_kb.py`。

## 实现与使用方法

新增样本时先记录四个核心文件的长度与 SHA，再确认 PE 版本、物品物理偏移和 `0xD9000` 行形态。只有这些证据一致后，才把样本加入现有变体；否则新建变体。

## 风险与边界

同样的 EXE 长度可能对应不同内容，不能只靠长度宣布精确匹配。当前两套山贼 1,148,928 字节样本与旧登记的 1,146,880 字节样本必须分开记录。

## 证据来源

`基底` 下八套本地目录、旧工具的纯数据布局实现、当前 Profile JSON 和自动读取矩阵。

## 十八州 → 复刻版 V10.1 迁移专项证据（2026-10-18）

完整逆向地址、记录宽度、消费者指令和样本 SHA 见 `验证/18州至V10.1迁移专项/逆向证据.md`。该文件限定于样本 `十八州 Ekd5.exe` SHA `215C6EF3DE2EB21E29CE99ED0543F7FBEE3728AC450242DDD670531CB7D0F3EB`、`ExtendData.dll` SHA `F2827380837060ADB43CEE0B0E399A2E8812A4507B4B2425C928A6D960AA7B11`，以及目标 V10.1 `Ekd5.exe` SHA `2594711168EA58258E40F3D804BF982DC376B58711C8E562EBE6B16E87A56B82`；不能推广到仅同名或同长度的其他基底。

已确认的可索引布局：根 `Item.e5` 为 256×25（逻辑 ID 256～511），根 `Itemmsg.e5` 为 256×200；`Effect.e5` 为 1024×256×4，`Effectmsg.e5` 为 256×8，`MeffStudy.e5` 为 1024×32×2，`Forge.e5` 为 256×64。Item 的 `+0x12/+0x13/+0x14` 轮转发生在 DLL 加载后的内存，不得对文件再次轮转。策略、物品和特效图标按成对序列读取，目标物理图号为逻辑编号的 `2N+phase+1`。透明规则使用索引 0 或 RGB(247,0,255) 掩码，不能用固定蓝色或角像素猜测。

V10.1 没有已验证的 `ExtendData.dll`、ID>255 消费者或四张扩展表的运行时接口，迁移器将 256 条扩展物品和 4 条扩展运行时能力逐项标为 `Incompatible`；物理文件落盘不等于游戏运行时支持。名称池容量/尾部差异、未知物品类别和根/E5 同名 `Spalet.e5` 也必须保留阻塞原因。逆向原始证据和全量迁移复读报告是能力边界的唯一依据。

### Meff 与发布证据（2026-10）

18 州样本 `E5\Meff.e5` 为 `Ls12`，`0x110` 起 64 个 12 字节大端索引，目录尾部存在基底特有的非零值；首条解码为 22 条播放记录、7 个平面、50ms、64×64。资源目录必须优先 E5 路径并逐条探针，坏条目不得使整档案变空；`N+1` 图号映射和 `255` 无动画规则与策略表一致。

`DataManager.App` 使用 `win-x64` framework-dependent single-file，目标机依赖 .NET 8 Windows Desktop Runtime；`Doro-white.ico` 以 ApplicationIcon 和嵌入资源两种方式编译进 EXE，发布目录验收只允许留下应用 EXE。

### 宝物类别字段复核（2026-10-20）

`复刻版 6.6 山贼国庆` 的 `Star.e5`（已登记 SHA 前缀 `AA3D4F92`）五个辅助样本逐行按 25 字节复核：天毒珠、太平要术、天毒珠（仿）、左氏春秋、凌风赤兔的 `+0x15` 特效值依次为 `1/5/60/22/7`，`+0x17` 适用兵种依次为 `6/0/6/255/27`，分别对应侠客/君主/侠客/所有兵种/上将。五行 `+0x13` 价格均为 `255`、`+0x18` 图鉴均为 `1`。这是辅助特效值、适用兵种和价格绑定的物理样本证据，不将 `+0x17` 误作价格。

图鉴勾选框、适用兵种下拉和宝物原始字段开放编辑属于用户本轮明确要求；可写政策不改变字节含义或未修改字节保留规则。`0x28=恢复SP`、`0x2A=HP上升`、`0x2B=MP上升`、`0x31–0x34` 策略/技能相关效果、`0x3A–0x3C` 任务/材料/工具，以及 `0x2C–0x30/0x35–0x39` 道具号标签来自用户确认；新增标签不登记为 EXE 消费者证据。重复编号的 MP 上升按 `0x2B` 处理，原请求的 `0x28` 明确保留恢复 SP。
