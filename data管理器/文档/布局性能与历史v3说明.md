# 1.2026.1111.1 布局、资源与历史存储说明

本版稳定缓存业务页的宿主，合并字体、DPI、大小变化引发的布局请求，修正范围预览在 150% DPI 下的尺寸，以及窄窗口工具栏滚动条遮挡按钮的问题。空间不足的编辑区域允许滚动访问。业务页的当前实体、子页和输入继续保留。

返回已有拓展页时，按绑定实例及数据版本复用控件。父页隐藏造成的有效 Visible=false 不再引发内部页先隐藏再显示、清理普通子页的重复布局；原输入校验与实体、文档版本更新仍然执行。

图片预览使用共享调度：同时解码最多 2 项，待处理队列最多 64 项，可见预览先于缩略图和后台任务；同一消费者只保留最新请求。共享图片的一个等待者取消，不取消仍有其他消费者的读取。切换项目或资源版本后，旧结果不会回填到新页面。

诊断统计区分队列等待和实际解码时间。各保留最近 256 个样本以计算 P95，同时保留生命周期样本总数与最大值；统计自身不会随运行时间无限增长。

图库隐藏时同时停用预览和缩略图，回收可见卡片并取消其读取；失活的图库不会因已排队的布局、滚动或尺寸回调重新生成卡片。再次显示时按原选择和滚动位置恢复，图片继续从共享缓存加载。

业务页显式下传预览活动状态，停用时停止动画、取消范围和下拉图片请求、释放预览像素；返回后保留资源编号、播放位置、未完成文字和光标。尚未挂到页面的新编辑器先保持预览失活，实际显示后才读取。迟到结果与新的用户输入分别有版本保护。

项目循环的堆快照定位到 Windows 下拉框辅助功能对象保留已释放控件时，其事件闭包继续持有整页的引用链。本版在下拉控件正常释放和 Disposed 通知后断开残留事件引用，保留使用期间的正常辅助功能。有限轮次是否全部回收及句柄变化见验收报告，不能据此承诺所有外部辅助功能客户端均立即释放原生对象。

相同的释放处理也覆盖拓展页的普通分页下拉框，包括整页关闭和局部重建。分页选择、实体切换、未完成输入校验及正常 Disposed 通知均有独立复测。

E5 预览档案缓存默认 128 MiB；可回收预览像素预算默认 96 MiB。两者不是整个程序的内存上限。正在显示的资源、在途解码、不可回收的编辑画布和修改候选分别计量。大型策略动画使用帧窗口；PNG/JPEG 源条带及单个大画布仍可能产生临时大分配。写入、冲突检查和显式重新读取继续读取新鲜文件。

新操作采用内部 history-v3：原始字节 SHA-256 去重，Brotli 快速压缩；不适合压缩的载荷保留原始编码。元数据、追加日志与载荷分离，历史列表不一次解码全部快照；恢复时只读取所选条目。历史页显示存储版本说明。

既有清单、快照、备份全部保留，不自动压缩迁移、删除或缩短历史。新操作和旧记录的状态变化写入 v3。升级后请用新版管理器进行历史撤回与前进；旧版无法识别 v3 的新操作及状态覆盖。历史目录应作为整体保存，不单独删去 blob、ledger 或旧清单。

延续现有历史时，将新版程序及随附许可放到原管理器所在目录，保留同级所有 `项目名_历史记录` 文件夹，且保持项目路径不变。也可以把这些历史文件夹完整复制到新版程序旁；单独从新的版本子目录启动不会自动读取父目录的历史。请勿同时用新旧版本修改同一项目。

事务仍校验 Profile、Variant、布局版本、完整文件 SHA 和语义结果。先持久化 blob、Prepare，再替换项目文件；全部成功后写 Commit。未知外部内容不自动覆盖。项目写入使用跨进程独占锁。

主窗普通保存将冻结后的历史压缩移到后台，期间暂时禁用输入并阻止重复保存、切换项目或关闭；完成或失败后恢复输入。恢复的历史载荷也在后台读取。候选构建、文件替换、语义复读以及图片编辑器的集成保存协调仍有同步阶段，部分大操作仍可能短暂等待。

本轮没有改变 EXE/E5/CCZRNG02/CCZRNG03 游戏格式、范围编号或名称显示，没有新增名称映射、名称池或名称编辑。调色板继续采用精确颜色优先、缺色选择最相近适用颜色。具体性能、有限轮次的句柄变化、未达到的目标和环境限制见随版验收报告。

源码解压后须保持 `data管理器/` 与 `形象管理器/` 同级；DataManager.Images 链接共享图像源码，两套 Core 共用 HistoryStorage。Windows 上安装 .NET 8 SDK 后可执行：

```powershell
dotnet build 'data管理器/src/DataManager.Tests/DataManager.Tests.csproj' -c Release
dotnet publish 'data管理器/src/DataManager.App/DataManager.App.csproj' -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
dotnet publish 'data管理器/src/RangeManager.App/RangeManager.App.csproj' -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

发布程序为 Windows x64、依赖 .NET 8 Desktop Runtime 的单文件程序。发布目录仅含程序、许可、说明与验收资料，不附游戏基底、运行历史、NuGet 缓存或开发临时目录。
