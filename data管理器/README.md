## 引擎扫描详情与写回

“引擎扫描”页签使用与人物/宝物页一致的双窗格：左侧 `ID：名称`（6.4 为 180 行，6.5/6.6 为 255 行，名称表外有静态调用的 ID 追加显示），顶部“仅显示有调用点”可筛选；右侧显示当前特效的标题、后缀、名称、Imsg 说明、当前调用点和全部调用点。切换特效、切换页签、切换项目、切换 Profile 或关闭窗口前，有未写入修改时会询问“先写入 / 放弃 / 取消”。

可写字段：

- 效果值模式：第 1 个 `push` 立即数；`0` 读数值、`1` 返回开关，其他值写入前二次确认。
- 叠加方式：第 2 个 `push` 立即数；`0` 叠加、`1` 不叠加、`2` 装备优先、`3` 待测试（二次确认）。
- 装备特效号：第 3 个实参的真实来源，可为直接立即数、已证明的定义指令或表项。按装备 selector 的低 8 位读取契约写回；255 为本功能的未分配值，适配器排除装备子通道的255匹配，个人／兵种通道继续执行。
- 个人/兵种特效号：第 4 个 `push` 立即数；修改后调用点移动到该名称表行，写入后按新 ID 重新定位，原名称行仍保留名称/后缀/说明。
- 计算立即数：`mov reg,imm; push reg` 或 `xor reg,reg; mov reg8,imm8; push reg`，仅在定义唯一、未被其他参数共享、定义与 push 之间无分支目标且无其他读取时可写；补丁改写定义指令的立即数，预览中标注“定义 0x…”。`movzx`/`lea`/`add`/`[ebp+…]` 等其他计算链只读。
- 代码洞调用：调用点由 `jmp` 跳到 NOP 填充区时，参数取跳转前的四个 `push`（如 6.4 `0x4D0023` ← `0x4CFFFD`）；四个立即数按普通静态调用写回，补丁落在代码洞的 `push` 上。
- 派生调用：包装桩把 `[ebp+…]` 转给核心，扫描再按每个调用者的常量落回特效 ID；已定位的装备字段可按共享绑定组修改，跨装备／个人／模式等角色共用的定义保持只读。判定入口由桩决定，派生调用不能改写 `E8` 目标。
- 判定入口：标准四参数入口为 `0x004101D9`、`0x0042518F` 和 `0x0041301E`。`0x00413009` 按寄存器聚合契约展示，不生成可分配的四参数项；派生与包装内部调用不开放入口改写。
- 名称：`Ekd5.exe` 名称槽（6.4 `+0xD0D60`；6.5/6.6 `+0x9E800`），每槽 16 字节；最多 14 个 GBK 字节，保留 `+0x0F` 后缀和非零尾部参数。
- 后缀：名称槽 `+0x0F`，`0x00..0x14`；`0x07..0x14` 为候选语义，写入前二次确认。
- 说明：`Imsg.e5` 的 `86000 + ID×200`，200 字节槽，可用 199 字节，末字节保留 NUL。

只读派生字段：函数入口（回溯 `55 8B EC`）、解析状态、调用点地址、名称来源、说明字节数、名称表行号。调用点表格的 tooltip 显示四个 `push` 与 `E8` 的原始字节证据。

右侧调用点区有五个页签：

- `调用点`：当前特效的直接静态调用和派生调用，列含桩类型、判定入口、四个参数和状态。
- `未归属调用`：非静态、非引擎内部的动态/计算/上层参数调用；显示参数摘要和首选只读原因，选中后可查看证据并点“写入此调用”编辑已知参数。
- `引擎内部`：核心/包装/取值入口函数体内的调用，单独列出，不参与特效归属，也不能写入。
- `派生/表驱动/循环`：包装桩派生、循环/静态表展开和局部基址循环展开。列含调用者调用、桩内调用、桩函数、参数摘要、状态和写入约束；装备号有真实来源时允许按共享绑定组修改，循环计算、索引及模式参数保留各自写入约束。
- `反汇编证据`：显示调用点、函数入口距离、桩内 push、最近指令与字节、四参数定义链、函数体调用、跳转来源、消费点和写回计划。

扫描计数保留四参数入口的全部 `E8` 调用，并单独报告引擎内部、有效、派生、表驱动、循环展开与二级包装数。历史报告中的 102/186/206 个原始调用包含了寄存器聚合器；当前对应三样本的四参数原始调用为97/181/199，聚合器另按自身契约分析。动态/未解析调用保留诊断，具体计数以当前文件的扫描报告为准。

表驱动调用来自三个循环：

- `0x4039D6`：6 项，个人号 6–11，装备号取 `0x437E19[i]`。
- `0x403A37`：4 项，个人号 13–16，装备号取 `0x437E1F[i]`；索引 2（个人 15）效果值为 0。
- `0x43CEFC`：3 项，个人号 3–5，装备号取 `0x43CFCD[i]`，回合恢复路径。

表字节按基底不同：6.5 为 `0x47/0x4B/0x2E/0x2D/0x2C/0x00` 与 `0x2D/0x2E/0x2B/0x2C`，6.6 为 `0x44/0x4D/0x71/0x30/0x58/0x4A` 与 `0x65/0x00/0x68/0x58`。表项装备号可以逐项写入，写入前会提示“会影响所有使用该表的对象”；循环上限、个人号基址、值/叠加和索引计算只读。

循环展开来自 `0x448FF8`：局部 `[ebp-8]` 由函数头 `push 0xA5`（6.5）或 `push 0xA0`（6.6）初始化，计数器 `[ebp-0xC]` 从 0 到 4，个人号为基址+索引：

- 6.5：165–169，装备 84。
- 6.6：160–164，装备 39。
- 6.4：该函数为 NOP 填充，无循环展开。

二级包装来自 6.4 `0x43E1A8`：它把参数 `[ebp+8] + 0x49` 交给 `0x412A87`。三个调用者：

- `0x41DC9E`：循环 0..7 → 个人号 73–80。
- `0x465AEE`：循环 0..7 → 个人号 73–80。
- `0x41FF7A`：常量 7 → 个人号 80。

共 17 条二级包装展开调用，装备 108，值 0、叠加 3，全部只读。

派生/表驱动/循环独有特效与“有名称槽但无调用”的特效会显示在状态栏和诊断中。三套基底当前独有集合为 3–16，以及 6.4 的 61/69/73–80/152、6.5 的 165–169 和 210（辅助连击率）、6.6 的 160–164 和 171（其疾如风）/185（辅助连击率）/240（※削弱连击率）。这些 ID 没有直接 `E8` 调用，只通过包装桩、表驱动、局部循环或二级包装触发。

写入流程：

1. 先在内存中生成逐字节预览；校验空值范围、`2` 字节 `6A` 压栈只能写 `0..127`、旧字节与扫描结果一致、两个入口/名称/说明的 SHA 基线未变。
2. 弹出“写入引擎预览”，列出文件、偏移、长度、原字节、新字节和项目；有错误时只能取消。
3. 写入前确认游戏没有从当前项目目录运行，获取项目内 `引擎写入/write.lock`，并把 `Ekd5.exe`、`Imsg.e5` 整文件备份到 `项目名称_历史记录/项目路径标识/引擎写入/备份/时间戳/`。
4. 统一走 `WorkspaceBinaryTransaction`：按 SHA 生成补丁、原子替换、逐字节复读，名称/后缀/说明再做语义复读。
5. 成功写入同一条数据历史，可“历史撤回”；失败时事务回滚文件，备份目录保留用于排查。

边界：加壳引擎或未知改造若静态不可见调用点/名称槽，详情页显示空状态并禁用写入；动态/未解析调用点按参数级写回计划处理，已知的直接或安全计算参数可在“写入此调用”中改写，上层参数、内存、算术链和引擎内部调用只读；派生调用只能改调用者已知常量，桩内常量与共享立即数只读，判定入口不能改写；表驱动调用只能改表项装备号，循环上限、个人号基址、值/叠加和索引计算只读；循环展开调用的局部基址、计数器、值/叠加/装备/个人号全部只读；二级包装调用的调用者参数、包装内常量与个人号全部只读；代码洞调用要求跳转前四个 push 全部为立即数或 `[ebp+…]`，否则仍按未知处理；外部工具同时修改时以 SHA 基线拒绝；有未保存数据草稿时必须先保存或撤销；真实基底只作为只读样本，所有写回测试使用临时副本。

## 保存、工作簿与恢复

普通页面编辑进入草稿，顶部保存与 Ctrl+S 会先收集当前文本框、数值、下拉、物理表单元格、台词和辅助分组的待保存输入；未失焦的修改也计入未保存状态。切换页面、项目、重新读取或退出前先处理当前输入，验证失败保留原输入并定位错误。

提交前核对 SHA，按字段生成补丁、保留未修改字节，在完整候选中复读目标值；临时文件替换后再核对完整文件与语义。全部验证和历史持久化成功后才接受新基准。重叠物理表或专用补丁对同一字节提出不同值时拒绝保存。可捕获的写入、复读或历史失败会恢复草稿并尝试回滚文件，外部再次修改或文件锁导致恢复受阻时明确报告冲突。没有实现断电、系统崩溃或强制结束后的自动恢复，逐文件替换不构成文件系统级多文件原子提交。

文本使用严格 GBK/CP936。人物姓名12、策略名10、宝物名14、兵种系及详细兵种名8、列传及Imsg说明/台词200字节；必杀名10和锻造名29仍是未确认完整消费者的保守预算。实际容量还会按本槽非零尾部参数收窄，界面实时显示已用和剩余字节，悬停查看依据。满200字节列传可保存，不统一减为199；无法编码字符、嵌入NUL和超限替换不会被截断或代写问号。原始超预算或坏GBK文本未改时保持原始槽，主动编辑须修复；尾空格、CR/LF及控制码原样保留。未知修改引擎的运行时说明标为参考证据。

业务页默认导出一个多工作表 XLSX，冻结表头和编号列，区分可编辑与只读列，使用导出基线识别本次修改及当前草稿冲突。整本校验后显示变更预览，再作为一条草稿应用。共享表按字段白名单投影，具体范围见 [业务工作簿交换](文档/业务工作簿交换.md)。

兼容入口保留每张物理表一个 CSV，使用中文文件名和中文列名；导入兼容旧英文文件名、原字段名和改名后保留元数据的文件。包含 schema、Profile、Variant、TableKey、LayoutRevision 和稳定 ID。旧 CSV 目录导入形成可整体撤回的草稿；物理表页只交换当前表。支持 UTF-8 BOM、UTF-16 LE/BE、GBK；重复 ID、未知列、越界、错误 RawHex、布局不匹配会明确拒绝。只读/保留列允许原值回导，禁止改写；派生显示列不导出。兼容旧式无元数据 CSV，元数据六个有效字段之后的空列可接受。

辅助分组由专用结构服务准备补丁，与普通草稿一起通过顶部保存写入同一次数据历史；页面“校验保存”也调用统一保存。名称池仍按专用服务和只读边界处理，不因文本预算而自动开放物理页。数据历史、资源历史和迁移备份统一放在 `data管理器.exe` 同级的 `项目名称_历史记录/项目路径标识/` 下，内部各自存放；项目名称来自实际打开的项目目录名，完整路径参与身份计算。历史列表仍统一按时间显示，保留原 SHA 检查、撤回和重做。项目内旧 `.data管理器历史`、`.data管理器形象历史` 兼容读取并接续到新目录。

辅助分组在自己的子页使用“导出 CSV”“导入 CSV”，以 `分组编号,兵种系编号列表` 交换完整分组，继续接受旧 `GroupID,JobSeriesIDs` 表头。点击“新增空白分组”后在右侧勾选兵种系；空白组可暂存，但必须选择成员或删除后才能保存。导入先验证版本、连续组号、重复、范围和安全区，只载入草稿；勾选、新增、删除和导入都支持统一草稿撤回/重做。顶部保存、Ctrl+S或子页“校验保存”提交分组与普通字段，切换页面保留分组草稿。顶部批量 CSV 处理普通物理表，分组不伪装成定长表。

人物、策略、宝物页只做资源关联预览。实际资源修改集中在图片设定；新增默认追加，删除/重排不会自动更新 Data、策略、脚本或地图引用。

图片格式的写入能力沿用原形象管理器：Pmap、Weather、DT 专用格式以及 Mark、未识别的 Mcall 布局保持只读，界面按资源显示状态；已支持的 R/S、Face/Tou、图标、动画和地图成对资源保留原有编辑与事务能力。资源写操作立即保存并进入独立资源历史，页面动态显示编号余量、固定槽、尺寸或配对限制；详情见 [资源事务写回验收](文档/资源事务写回验收.md)。

R/S 图库使用已验证的人物指定表提供“空闲”筛选和已使用引用提示；缺少证据时隐藏该筛选并显示原因。大/小动画页提供“播放动作”和空格播放。

## 一键迁移

第一个目录为源、第二个为目标。先预览差异，再逐项覆盖/跳过/合并，默认全部跳过。合并只补目标空值，已有资源冲突在合并时保留目标；覆盖才替换。源目录始终不修改。

跨版本数据按 TableKey、ID、字段与目标 Codec 映射，禁止复制源物理偏移。资源按相对路径和目标已有存储位置比较。先在临时副本生成候选，再备份目标、逐文件替换、复读并写迁移历史；失败恢复目标，删除新建资源。无法映射的布局和存储差异在预览中说明。

差异窗口支持按表/资源筛选，对当前筛选批量覆盖、跳过或合并。目标缺失四种拓展文件时，单独选择“新建物理文件”，按目标布局初始化，再选择需要导入的逻辑字段。已支持 Itemicon.dll → E5/Item.e5、Mgcicon.dll → E5/Mtem.e5 的大小图成对转换，透明规则归一后逐像素验证，并保留目标未覆盖条目。未经验证的程序 DLL/加载器不会作为图片库覆盖。

共享特效名称和装备特效名称池按已确认策略全部跳过，保留目标名称，差异报告只显示一条汇总忽略项。辅助分组按逻辑兵种系 ID 使用目标 PE/安全区服务迁移。已验证历史与必要的 INI/资源证据会带入临时项目，原有历史不重复追加。其他只读字段、目标无法容纳的值和 raw 保留尾部差异仍列出具体原因。

十八州根目录 Item.e5（256×25）和 Itemmsg.e5（256×200）是 ID 256～511 的拓展物品，E5/Item.e5 是宝物图标，二者按路径和几何区分。目标没有验证的拓展物品存储/消费者时，仅生成一条“拓展物品已忽略”，不复制根目录文件，也不影响普通宝物及图标迁移。Effect、Effectmsg、MeffStudy、Forge 可按目标物理布局迁入和复读；目标游戏缺少消费者时单独显示运行时诊断，不宣称功能已启用。

迁移在后台执行，差异窗口使用虚拟表格。临时目录放在目标盘，提交前检查空间、源/目标 SHA；支持只读文件的备份/恢复及失败回滚。最终十八州到 V10.1 验收见 `验证/18州至V10.1迁移专项/全量逻辑迁移最终验收-20261018/验收摘要.md`。只对完整临时目标副本写入，原始源/目标目录完整 SHA 保持不变。

6.5 固定布局与 6.6 动态布局之间的辅助装备/道具使用专用映射：按目标 Codec 转换 `+0x11` 实际效果和 `+0x12` 类别标记，覆盖低段和高段物品。只有两侧类别都能确认时才转换；普通装备或未知行与辅助/道具之间的类别转换整行拒绝，并列出原因。

## 版本证据边界

支持 6.5，以及 6.6 标准、17 字节兼容、旧山贼三种布局。

- 6.6 撤退文本只写 Imsg.e5 +491600 的 49×200 区域；旧 +440200 不作为撤退写入目标。
- 6.5 策略施展地形为 Ekd5.exe +0x1FECC，30 项火/水/风/地掩码。
- 6.6 策略地形和 R/S 指定不继承 6.5 地址：程序先对 Ekd5.exe 做 PE32 节映射和实际消费者签名校验，证据完整时按探测到的偏移开放读写，证据不足时显示不可用并保持只读。
- 6.5 R/S 写入需已验证 EXE SHA，或经补丁和前后 SHA 完整校验的本项目历史链。未知 EXE 缺少本项目 INI/资源/样本证据时不可用；结构检查通过时仍只读。INI 偏移冲突或越界会拒绝使用，正常保存及历史撤回/重做不会因 SHA 改变丢失证据。
- 特殊暴击人物映射需 PE 可执行节引用和 21 个 ID 校验通过才加载。普通暴击类型映射 21+类型×3 的三行；撤退文本按人物 ID 0..48 定位。缺少特殊映射证据时，人物暴击文本只读。
- 6.5 名称池按非空 GBK 零分隔字符串解析，原位修改保留相邻名称/填充；6.6 固定槽保留隐藏尾部并校验哨兵。
- 未知数值具备可靠偏移、宽度和边界即可写；缺少布局证据的表不会猜测开放。这些状态会显示在界面和扫描中，不表示每个衍生 MOD 都已通过游戏实测。

## 模块结构与验证

`DataManager.Core` 处理 Profile、Codec、领域服务、CSV、历史、事务、迁移，保持 net8.0；`DataManager.Images` 通过窄适配器及共享源码复用本地形象模块；`DataManager.App` 处理固定布局、业务页、搜索与迁移选择。Core 不引用 Windows 图像程序集。

测试在临时副本验证四种布局、人物台词、逐表 CSV 往返、UTF-16/GBK、跨表撤回/保存、历史恢复、迁移过期计划/资源 SHA/中途失败回滚及 WinForms 控件。本轮字段矩阵真实9套基底通过8966个字段首末边界、352次整表保存/重开复读/撤回；旧山贼合成fixture另通过772个字段边界、39次事务。另有108条未测或不适用记录、7条原始坏GBK警告，未计入通过，非预期失败0。原始报告见 [字段写回矩阵](验证/写回完善/字段写回矩阵.csv)。这不是每条中间记录、全部取值或所有游戏消费者的穷举测试。

既有完整截图覆盖实际窗口1280×720、1727×980；测试机桌面会把请求的1920×1080窗口限制为后者，因此不将其作为1920×1080实测结果。本轮UI检查和字体125%/150%模拟不等于Windows真实高DPI、多屏缩放验收。具体输入法的人工候选/合成流程、真实DPI和游戏内语义仍未完成实测；程序消息及离屏控件检查不能替代这些结果。最终Release与完整测试状态以 [本轮验收说明](文档/完整写回与动态约束验收.md) 为准。

本轮矩阵使用9套真实样本，包含6.5和八套6.6；旧山贼变体保留定义、Codec与强制布局合成测试，当前缺少完整原件，尚无该原件的读写实测。具体来源见 `知识库/90-证据索引.md`。

## 紧凑界面、范围与性能

人物、兵种和商店使用单详情页；宝物仅为八十项部队许可保留单独大页，策略仅为八十项学习等级和全局施展地形保留大页。兵种系地形发挥/移动消耗并列，克制为 0–19、20–39 两个紧凑矩阵，显示真实兵种系名称。诊断信息通过顶部“诊断详情”查看。

普通暴击可选 0–25 类型，三句文本由同类型人物共享；特殊暴击可选 0–20 槽，槽值是人物编号、空槽为 1024。切换模式时清除旧绑定；覆盖其他人物占用的特殊槽必须勾选确认。特殊槽号对应 Imsg 文本行，不把人物编号误作文本行。

范围字段从 0 开始，Hitarea/Effarea 的 E5 图号从 1 开始：字段 0 预览图 1、字段 1 预览图 2。范围专用层只加一次 1；缺图显示占位并保留可编辑数字。

同类实体切换复用固定字段控件、项目名称索引及资源目录。预览在后台加载；切换到不同资源时取消旧请求并验证绑定代次，同资源保留画面和播放进度，隐藏页暂停，项目切换/退出时释放。原生下拉的缩略图异步回填会刷新弹出列表；重新绑定范围下拉会刷新自身缩略图，避免资源替换后仍显示旧图。
