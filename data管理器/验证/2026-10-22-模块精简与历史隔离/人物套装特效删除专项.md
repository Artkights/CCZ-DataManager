# 人物／套装特效模块删除专项验收

本专项于 2026-10-22 完成。源码先由主任务上传 GitHub 原始基线，然后才执行删除。当前源码不再包含专用页实现、分配域服务、剧本参数解析／补丁服务、套装校验器、专用工作簿数据集与特效分配迁移器。

## 删除与保留边界

- 已删除顶部业务页及 `BusinessPageKind.Effects`；显式保留其他业务页原数值，4 留空。
- 当前 6.5／6.6 profile 的所有变体均删除 `class-effects`、`personal-effects`、`effect-descriptions`，普通物理表入口也不再读取这些表。
- `effect-names` 保留为共享只读名称表，归属拓展数据，不加入拓展业务表的导入导出集合；运行时名称探测不恢复写入能力。
- 保留宝物装备特效名称池、拓展数据的“人物特效／特效成长／策略学习／锻造配方”，保留人物、兵种系、兵种、宝物、策略、商店与形象功能。
- `*.before-simplification.json` 为删除前的冻结清单，与现有 `*.extenddata-v1.json` 一样，仅用于重现已发布旧布局哈希，不提供当前模块、编辑器或写入能力。
- 旧布局兼容必须满足：冻结前版精确删除这三张表，并将共享名称表改只读后，能逐字段重现当前完整 schema。未知哈希及其他 schema 改动不获此兼容授权。
